# Telegram-like Messenger (MVP)

Это рабочий мини-мессенджер в стиле Telegram (не официальный клиент Telegram), который можно запустить на Windows 10 с публичным IP.

## Что умеет
- Регистрация и вход.
- Общий чат в реальном времени (WebSocket).
- Приватные сообщения через команду `/w username текст`.
- История последних 100 сообщений.
- SQLite-хранилище (файл `chat.db`).

## Быстрый запуск (Windows 10)
1. Установите Python 3.11+.
2. Откройте PowerShell в папке проекта.
3. Выполните:
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   uvicorn app.main:app --host 0.0.0.0 --port 8000
   ```
4. Откройте в браузере:
   - локально: `http://localhost:8000`
   - с другого устройства: `http://<ВАШ_БЕЛЫЙ_IP>:8000`

## Для доступа из интернета
- Откройте порт `8000/TCP` в Windows Firewall.
- Если ПК за роутером, пробросьте порт (port forwarding) на локальный IP ПК.
- Рекомендуется использовать reverse proxy + HTTPS (например, Nginx/Caddy).

## Важно
Это **не копия исходного кода Telegram** и не совместимо с серверами Telegram. Это самостоятельный учебно-практический проект с похожей базовой идеей чата.
